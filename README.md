# WeForm

✨ Projeto inspirado no design original criado no Figma — link: https://www.figma.com/design/w11Rpk9e1tqreNMtHAVrDm/We-Form

## 🎯 Sobre

O **WeForm** é uma aplicação web simples que implementa o layout e a interface definidos no design do Figma, permitindo que você visualize e interaja com um formulário / interface conforme o design original.  

Ele serve como pontapé inicial para um front-end baseado em design de UI/UX, ideal para aprender como traduzir mockups visuais em código real.

## 📂 Estrutura do Projeto

WeForm/
├── index.html → Estrutura HTML da interface
├── style.css → Estilos e layout (CSS) baseados no design
├── script.js → Funcionalidades & lógica JS (validação, interações, etc)
├── (outros arquivos/pastas conforme o projeto)
